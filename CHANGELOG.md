# Changelog

All notable changes to Followspot are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses
[Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-18

First public release.

### Added

- Click rings for left and right clicks, spotlight, cursor halo and one-shot area highlight.
- Global shortcuts `⌥F1`–`⌥F4`; every shortcut toggles only its own feature, `Esc` is never captured.
- Menu bar settings: accent and right-click color (8-color palette), sizes, dimming levels,
  crosshair guides. All settings are remembered.
- Works on all connected displays, in full-screen apps and across Spaces.
- One-line installer with checksum verification, universal (Apple Silicon + Intel) release builds.
